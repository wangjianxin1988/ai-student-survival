## 三、关键问题修复清单

### 3.1 OAuth 升级（最重要的修复）

**修前**：scope = `webmasters.readonly`，无法：
- ❌ PUT resubmit sitemap → HTTP 403
- ❌ Request Indexing → HTTP 403
- ❌ 后果：sitemap 81 天没动，Indexed 0/468，新内容 Google 完全不知道

**修后**：scope = `webmasters + webmasters.readonly`（full）
- ✅ PUT resubmit sitemap → HTTP 204
- ✅ Google 1 秒内下载新 sitemap
